# Сокровищница Робосычика

Первый демонстрационный интерфейс VK Mini App.

- Две вкладки: личная и общая сокровищница.
- Показываются только найденные артефакты.
- Фильтры по редкости, увеличение карточки, учёт повторок.
- Деревянные полки и три карточки в ряд на телефоне.
- Пока используются **вымышленные демонстрационные данные**, реального API нет.
- В репозитории **нет** фотографий секретных артефактов, VK-токенов или паролей.

## Размещение на GitHub Pages

Загрузите `index.html`, `style.css`, `app.js` в корень репозитория. В Settings → Pages выберите Deploy from a branch → main → /(root). После публикации откройте `https://anaryann.github.io/robosychik-treasury/`.

**Не включайте публичный доступ к VK Mini App до подключения реального API и проверки авторизации.**

Следующий этап: отдельный Google Apps Script для выдачи только открытых артефактов, проверка подписи VK launch params и безопасная выдача изображений из закрытого альбома.
