# Сокровищница Робосычика, v3

В этой версии сайт показывает реальные находки из Google-таблицы через публичный read-only Google Apps Script API.

## Порядок установки

1. В отдельном проекте Apps Script «Сокровищница Робосычика API» замените Code.gs содержимым файла `Code.gs` из этой папки. **Сохраните свой настоящий SPREADSHEET_ID** в CONFIG (в шаблоне стоит заглушка).
2. Выполните **Развернуть → Управление развертываниями → Изменить (карандаш) → Версия: Новая версия → Развернуть**. Старый URL /exec сохранится.
3. Проверьте URL `/exec?action=health`: должна быть версия 2.
4. В GitHub репозитории `robosychik-treasury` замените только `index.html`, `style.css`, `app.js` файлами из этой папки. `Code.gs` в GitHub загружать **не нужно**.
5. Откройте GitHub Pages. Вкладка «Общая сокровищница» покажет найденные карточки. Личная коллекция определяется через `vk_user_id` при запуске внутри ВК.

## Важно

- API не раскрывает полный каталог, но позволяет запросить коллекцию по любому VK ID. Это временный read-only прототип без проверки подписанных параметров запуска ВК.
- Фотографии из закрытого альбома пока не подключены, отображаются заглушки.
- Публичный JSONP нужен из-за ограничений CORS Apps Script. Нельзя использовать этот метод для операций записи или секретных данных.
- При обычном открытии GitHub Pages без VK ID отображается общая коллекция и пустая личная.
